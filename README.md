# Zombie Revolution -SQL Analysis

Учебный аналитический проект по исследованию мобильной игры **Zombie Revolution**.

Цель проекта проанализировать пользовательскую активность, технические проблемы, результаты маркетинговых активностей, монетизацию и лояльность игроков с помощью SQL.

## Задачи проекта

В рамках анализа были исследованы:

- количество пользователей и игровых сессий;
- средняя продолжительность игровой сессии;
- технические проблемы и незавершённые сессии;
- DAU, WAU, MAU и Sticky Factor;
- результаты маркетинговой акции;
- финансовые показатели и изменение стоимости кристаллов;
- K-factor;
- эффективность нового канала привлечения;
- лояльность пользователей.

## Основные результаты

- Доля игровых сессий без времени окончания составила **12,01%**.
- Техническая проблема значительно чаще встречалась на **iOS - 18,98%**, чем на **Android - 0,75%**.
- Максимальный MAU был зафиксирован в марте 2023 года - **1 544 пользователя**.
- Среднее количество кристаллов за покупку снизилось с **29 до 23,08**, примерно на **20,4%**.
- K-factor игры составил около **0,92**.
- Пользователи нового канала привлечения ноября–декабря 2022 года проводили в игровых сессиях в среднем около **217 минут**, против **177 минут** у остальных пользователей.
- Для анализа лояльности использовались критерии, основанные на реферальной активности и платежах пользователей.
